ons plan is om een gokwebsite te maken
we zijn van plan om met slots te beginnen en daarna verder te kijken of we nog tijd hebben voor een van de onderstaande spellen.



Krasloten (scratch cards) – een grid met vakjes die je "wegkrast" (klikt), match 3 symbolen = winst

Plinko – balletje valt door pinnetjes naar beneden in bakjes met verschillende prijzen. Visueel gaaf, logica kan simpel (random pad) of met echte fysica

Crash game – een grafiek/multiplier loopt omhoog, jij moet op tijd "cash out" klikken voordat het "crasht". Erg populair op echte gokwebsites, en de kern-logica is niet heel moeilijk

Blackjack-lite – vereenvoudigde versie zonder split/double, gewoon dichter bij 21 komen dan de computer
